# Portfolio — Valentin Combier

Mon portfolio personnel présentant mon parcours, mes compétences et mes projets.

**[valentincombier.com](https://www.valentincombier.com/)**

## Stack

- **React 18** + **Vite**
- **Bootstrap 5** — mise en page et composants
- **CSS** — animations (transitions et keyframes, sans dépendance JS)
- **EmailJS** — formulaire de contact sans backend
- **React Icons** — icônes

## Sections

- Accueil avec effet typewriter et animation particules (mise en pause hors écran,
  désactivée si `prefers-reduced-motion`)
- À propos
- Compétences (Frontend, Backend, Outils & DevOps)
- Projets
- Expériences
- Formations
- Contact
